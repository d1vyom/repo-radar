# RepoRadar

A production-quality GitHub repository discovery platform.

## Architecture

- **Framework:** Next.js 14 (App Router)
- **UI:** React, Tailwind CSS, shadcn/ui, Lucide
- **Database:** Supabase (PostgreSQL)
- **API:** GitHub REST & GraphQL APIs
- **Deployment:** Vercel

## Local Development

1. Clone the repository.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and populate the keys.
4. Run `npm run dev`.
